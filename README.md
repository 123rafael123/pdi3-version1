# Proyecto Médicos VR

Simulación de cirugía y atención médica en realidad virtual para Meta Quest.

## Requisitos

- Unity 2022.3.62f2
- Android Build Support, SDK/NDK y OpenJDK instalados desde Unity Hub
- Meta XR All-In-One SDK
- Meta XR Simulator para pruebas en PC
- Meta Quest Developer Hub para instalar el APK en el visor

## Cómo abrir el proyecto

1. Clonar este repositorio.
2. En Unity Hub, seleccionar **Add project from disk**.
3. Elegir la carpeta raíz del repositorio.
4. Abrirlo con Unity 2022.3.62f2 y esperar a que Unity regenere `Library`.

## Escenas principales

- `Assets/NivelVR/Escenas/Nivel_1_Quirofano.unity`
- `Assets/NivelVR/Escenas/Nivel_2_Urgencias.unity`

El APK y las carpetas generadas por Unity no se guardan en Git.
